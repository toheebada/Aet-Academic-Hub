# Aet-Academic-Hub
Academic Excellence Team — FUTMINNA Academic Hub

The site now supports browser-local student activity without requiring sign-in:

- Save resources for later and view recent resources.
- Mark resources as studied and keep a local study streak.
- Store CBT attempt summaries and average performance locally.
- Open a `My activity` page from the primary navigation.
- Cache the application shell for repeat/offline loading where the browser supports it.

Student activity is stored in the browser's local storage and is not tied to a student identity.
